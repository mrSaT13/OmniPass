# OmniPass (ОмниПасс) 💳📲

> **OmniPass** — это современное высокотехнологичное мобильное приложение на базе **Jetpack Compose** и **Material Design 3**, превращающее ваш Android-смартфон в универсальный зашифрованный «цифровой карман» для карт лояльности, пропусков, банковских карт, RFID/NFC-меток и контроля личных финансов со встроенным ИИ-сканером чеков на базе **Gemini API**.

---

## 🚀 Основные Функции и Фичи (Features)

Приложение реализует мощные технологические компоненты, обеспечивающие максимальный комфорт и интерактивность:

1. **👛 Безопасный Картхолдер**: Хранение скидочных карт, пропусков, билетов и штрих-кодов в одном зашифрованном локальном Room SQLite хранилище.
2. **💳 Реалистичный 3D-Стек без Перекрытий**: Карты отображаются в виде трехмерного веера (как в Apple Wallet) с отрицательным Y-сдвигом. Задние карты красиво выглядывают сверху и не перекрывают переднюю активную карту. Нижняя панель навигационных синих стрелок позволяет быстро переключаться между ними в один тап.
3. **📸 Собственные Фото Карты**: Теперь вы можете прикрепить настоящее фото физической карты прямо из галереи устройства через Photo Picker. Изображение будет установлено в качестве фона карты на главном экране веера и на детальной панели просмотра!
4. **👁️ Умный Экранный Бустер Яркости**: Приложение автоматически увеличивает яркость экрана до 100% при нажатии на штрих-код или карту, облегчая считывание сканерами на кассе.
5. **🎛️ Живой Сканер Камеры (CameraX)**: Встроенный видоискатель камеры с анимацией лазерного луча позволяет наводить на штрих-код в реальном времени.
6. **🔌 Локальное Оффлайн-Распознавание**: Мы внедрили физический тумблер в настройках сканера. Если пользователь не желает задействовать облачные ИИ-сервера, он может использовать автономное локальное распознавание, которое мгновенно считывает и генерирует данные карты без подключения к интернету!
7. **🧠 Чек-ИИ (Сканирование расходов)**: Интегрирован ИИ-анализатор чеков через Gemini API. Он автоматически вычленяет название магазина, категорию, сумму транзакции и отдельные товары в общую ленту расходов.
8. **🌐 Полноценная Поддержка RFID/NFC-меток**: Приложение автоматически перехватывает RFID/NFC-метки при касании к физическому считывателю с помощью фонового диспетчера `NfcAdapter`! Считанный UID мгновенно заносится в поля пропуска на экране добавления или открывает соответствующую карту на домашнем экране.
9. **🔒 Надежная Защита Данных и Полный Сброс**: Биометрическая аутентификация защищает балансы ваших банковских карт. На экране настроек доступен «Экстренный сброс данных», который полностью очищает Room БД и восстанавливает статус онбординга.
10. **🎉 Умный Однократный Памятка-Гайд**: Обучающий гайд больше не выскакивает надоедливо при каждом запуске! Статус онбординга сохраняется в SharedPreferences, а сбросить его можно только вручную из настроек профиля.

## 🎨 Дизайн и Визуальное Совершенство

Интерфейс спроектирован по передовым спецификациям **Material 3 UI**:
* **Space Blue & Obsidian Palette** — Глубокий, контрастный темный фон (`#03070E` / `#0C1420`), снижающий усталость глаз.
* **Градиенты Premium-класса** — Сапфировые, неоновые, изумрудные и карамельные подложки карт, создающие эффект физического пластика.
* **Эффектные Микро-анимации** — Плавные переходы страниц (`AnimatedContent`), пульсирующие NFC радары и эффект лазерного луча при активации ИИ-сканера.

## 🗺️ Структура Экранов Приложения

1. **Приветственный Онбординг (`OnboardingScreen`)**: Выбор имени, инициализация БД, активация русского или английского языка, инструкции по безопасности.
2. **Главная Панель (`HomeScreen` / Cards)**: Стек сохраненных карт с горизонтальной прокруткой, быстрый выбор балансов, карусель категорий, индикатор бесконтакта.
3. **Добавление Карт (`AddCardScreen`)**: Конструктор пресетов (Сбербанк, Т-Банк, Starbucks, Пятёрочка, Магнит или свой вариант), генератор случайных Payload-меток, выбор градиентного дизайна и типа карты.
4. **Просмотр Деталей (`CardDetailsScreen`)**: Интеграция штрих-кода, кнопка буста яркости экрана, запуск NFC-волн и **раздел реальных скидок магазина** (карта подтягивает персонализированные предложения Starbucks, Магнит и др.).
5. **Аналитика Финансов (`FinanceScreen`)**: График баланса, фильтрация (Расходы/Доходы), ручной ввод и **Сканер Чек-ИИ** с симуляцией захвата чека камерой.
6. **Настройки Профиля (`ProfileScreen`)**: Выбор языка, палитры цветов, тумблер извлечения темы, URL-адреса для WebDAV/CalDAV и справочный мануал.

## 🛠️ Как запустить и собрать APK / Выгрузить на GitHub

Так как проект собран в единой экосистеме **Google AI Studio Build**, управление репозиториями и сборка релизных версий автоматизированы и вынесены в визуальный интерфейс платформы. 

### 1. Как скачать скомпилированный APK-файл?
Мы уже выполнили сборку APK в текущей сессии через команду `gradle assembleDebug`!
Вы можете скачать собранный файл прямо в браузере:
1. Перейдите в правое верхнее меню настроек/экспорта **Google AI Studio**.
2. Нажмите кнопку **Download APK** (или **Generate APK/AAB**). Среда упакует и выдаст вам готовый файл для установки на любой Android-телефон.

### 2. Как залить проект на GitHub?
Синхронизация с вашим аккаунтом GitHub встроена в панель AI Studio:
1. В правом верхнем углу интерфейса AI Studio нажмите на кнопку **Push to GitHub** (или иконку GitHub в верхнем меню).
2. Авторизуйтесь под своим аккаунтом GitHub и выберите имя репозитория (например, `OmniPass-Android`).
3. Платформа AI Studio автоматически создаст репозиторий, зальет туда весь исходный код, ресурсы проекта и этот файл README.

### 3. Запуск на локальном ПК (Android Studio)
Если вы хотите продолжить разработку локально:
1. Экспортируйте проект в формате ZIP (кнопка **Export as ZIP** в AI Studio) или склонируйте его из вашего нового GitHub репозитория.
2. Откройте папку проекта в **Android Studio (Ladybug или новее)**.
3. Дождитесь Gradle-синхронизации (все зависимости прописаны в Version Catalog `gradle/libs.versions.toml`).
4. Подключите физическое устройство или эмулятор и нажмите кнопку **Run app (Shift+F10)**.

## 🔒 Использование API Ключей (ИИ-Сканирование)
Для полноценной работы модуля «Чек-ИИ» (распознавание чеков через Gemini API) укажите ваш Gemini API ключ в **Secrets Panel** (Панели секретов) в AI Studio под именем:
```env
GEMINI_API_KEY=ваш_api_ключ
```
Приложение автоматически считывает его через класс `BuildConfig.GEMINI_API_KEY` и бережно передает запросы напрямую на сервера Google AI Studio, обеспечивая полную безопасность пользовательских данных. При отсутствии ключа приложение бесшовно использует демо-режим с локальной симуляцией распознавания чеков Starbucks и Магнит.
